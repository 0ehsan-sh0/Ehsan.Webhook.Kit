Task 05 — Handler boundary and execution modes

Complete

Evidence

  • ADR 0005 records the hidden raw-body boundary, typed WebhookContext access, synchronous default, and explicit asynchronous mode.
  • WebhookContext exposes metadata, headers, and GetPayload<T>(), while WebhookProcessor owns sequential typed dispatch.
  • Handler, context, and integration tests verify scoped resolution, cancellation, and fail-fast ordering.

Boundary

Application handlers do not receive a public raw-body property. The asynchronous channel is a process-local delivery mechanism.
