Task 06 — Deduplication claims and Event ID fallback

Complete

Evidence

  • ADR 0006 requires an atomic store claim and makes Event ID the default identity.
  • WebhookDeduplicationKeyFactory and DefaultWebhookDeduplicator implement provider-scoped keys and explicit SHA-256 fallback.
  • Deduplication and concurrency tests cover one winner, atomic claims, and the missing-Event-ID policy.

Boundary

The body-hash fallback is opt-in and deterministic; it is not a general business idempotency guarantee.
