Task 09 — Provider customization and payload validation

Complete

Evidence

  • ADR 0009 records provider-neutral header/JSON extraction, DI replacement, and non-retryable typed payload failures.
  • ADR 0010 production behavior is delivered in WebhookSignatureInput, timestamp options, and the endpoint pipeline.
  • Extractor, deserializer, security, and Task 28 custom-extractor integration tests cover the delivered contract.

Boundary

Missing Event Type is different from an unregistered Event Type. The latter is acknowledged as Ignored; the former is a payload failure.
